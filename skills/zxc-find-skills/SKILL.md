## Install
List available skills:

```bash
npx skills add ki7ick/zxc-skills --list
```

Install:

```bash
npx skills add ki7ick/zxc-skills
```

## Notice
1. Ask for the user's agreement before adding any new skills.
2. Ask questions to confirm the installation location with the user.
